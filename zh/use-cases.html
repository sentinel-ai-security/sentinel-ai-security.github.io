应用场景

凡是 AI 拥有真实权限的地方，都需要 Sentinel

Sentinel 短期并不会进入所有行业，而是选择权限清晰、风险高、客户愿意 付费且容易构造 Demo 的场景作为滩头市场。

行业/场景 Agent 权限 典型风险 Sentinel 价值
金融 / 财务 付款、报销、授信、交易建议 欺诈、错误支付、敏感信息泄露 上线前验证 + 高风险交易实时拦截
企业办公 邮件、CRM、HR、内部知识库 越权访问、隐私泄露、错误外发 权限边界验证 + 实时行为检查
软件与 IT 代码仓库、云资源、运维工具 供应链攻击、权限升级、破坏性操作 工具调用验证 + 关键操作人工升级
制造 / 机器人 设备控制、采购、排产、物理动作 生产中断、错误控制、物理安全 场景化验收 + 实时安全边界
滩头市场

从权限边界最清晰的场景切入

首要客户应是正在采购或部署高权限 Agent 的业务企业，优先验证金融/ 财务、采购和内部工具工作流等场景。企业采购方天然需要独立于 Agent 供应商的安全证据。
